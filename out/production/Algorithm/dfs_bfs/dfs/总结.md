## **DFS（深度优先搜索）**
### **特点**
- 采用 **递归** 或 **栈** 方式进行搜索。
- 适用于 **搜索全部路径、连通分量、回溯问题（如组合、排列）**。
- 常用于 **树的遍历、图的遍历、迷宫问题、组合问题、全排列**。

### **常见题型**
1. **二叉树遍历（前、中、后序遍历）**
2. **求二叉树的最大深度**
3. **路径总和**
4. **子集、全排列、组合**
5. **岛屿数量（连通块问题）**
6. **迷宫问题**
7. **图的连通性判断**

### **Java 代码示例**
#### **1. 二叉树的前序遍历**
```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int x) { val = x; }
}

public class DFSExample {
    public void preOrder(TreeNode root) {
        if (root == null) return;
        System.out.print(root.val + " ");
        preOrder(root.left);
        preOrder(root.right);
    }
}
```

#### **2. 岛屿数量（200. Number of Islands）**
```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        int count = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }
        return count;
    }

    private void dfs(char[][] grid, int i, int j) {
        if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || grid[i][j] == '0') return;
        grid[i][j] = '0'; // 标记访问
        dfs(grid, i - 1, j);
        dfs(grid, i + 1, j);
        dfs(grid, i, j - 1);
        dfs(grid, i, j + 1);
    }
}
```
